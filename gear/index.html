    Read these numbers with care
    • Source: Firebase Analytics export to BigQuery (analytics_538473390), Android only. Only intraday tables exist for this project, so the latest day is partial and recent days can still change slightly.
    • Scope: release builds 1.0.x from 12 Nov. Development builds (0.0.x) and devices flagged as test devices are excluded. Build 1.0.0 is grouped with 1.0.1.
    • Retention counts an install as retained on day N if it logged any event that calendar day (UTC date of the export). Builds with fewer than 50 installs are left out of the curves.
    • Crash is the share of installs that logged at least one app_exception. ANR rate is in Play Console (Android vitals), not here.
    • Ad revenue is the impression-level value reported by the ad network SDK, before any network adjustments.
    • No UA cost is in this data, so CPI and ROAS are not shown. Traffic is Google Ads (App campaigns).
    • Small samples: recent builds have few installs. Read single-digit day-7 counts as early signals, not results.
