Weekly report — 9 to 15 October 2026

Fri 09-10 to Thu 15-10 · excludes China unless stated · queries dashboard/weekly_sql_1016/

IAP revenue rose to $1,029 (+68%) on 468 DAU (-7%). Without the week's top payer it is $882 vs $546 (+62%), so this is not one whale. The payer count did not move (39 vs 40); each payer spent more.

v36 replaced v34 over 10–11 Oct and carried 51% of the week's DAU. It shipped 10 new packs; together they earned $89, 9% of IAP. Existing packs went from $608 to $940.

5 things worth noting

  1. Revenue is up and it is broad. +62% excluding the top payer; the gain is spread over Remove Ads (permanent and 30-day), the Tiny Guide pass, the mythic combo and loot storage, not a single SKU.
  2. The new packs are a small part of it so far. 10 SKUs first seen since 25 Sep earned $89. Flameborn pass ($30.70, 1 buyer) and Hero Growth ($22.48, 2) lead; Flameborn+, campaign.20.plus, campaign.65 and daily.challenge.key.3 have taps but no purchase yet. Most only had 3–5 days live.
  3. Campaign packs reached players earlier than planned. campaign.20 / .20.plus / .65 appear on v36 from 12–14 Oct; the build plan had them in B3 (rollout 19–21 Oct). Check with the production team whether the stage 20 / 150 difficulty change shipped too.
  4. Players are falling, not growing. DAU 818 → 468 in five weeks and installs are flat at ~843/week. Revenue per DAU is carrying the week; without new installs this does not compound.
  5. The week's top payer is on the old build. United States, v34, 17 purchases, $146.83. v34 still carried 30% of the week's DAU; by 15 Oct only 28 daily users were left on it.

  SELECT d, u,
    ARRAY_AGG(v IGNORE NULLS ORDER BY ts DESC LIMIT 1)[SAFE_OFFSET(0)] v,

-- One row per product SKU x day x version (ex-China): store taps and purchases, plus each SKU's first day in the export.
WITH ev AS (
  SELECT PARSE_DATE('%Y%m%d', event_date) d, user_pseudo_id u, event_name e, app_info.version v,
    event_value_in_usd usd,
    COALESCE((SELECT value.string_value FROM UNNEST(event_params) WHERE key='product_id'),
             (SELECT value.string_value FROM UNNEST(event_params) WHERE key='position')) sku
  FROM `tiny-knightfall-idle-rpg-game.analytics_538412813.events_intraday_*`
  WHERE event_name IN ('in_app_purchase', 'purchase_click', 'first_purchase')
    AND geo.country != 'China'
),
x AS (SELECT * FROM ev WHERE sku LIKE 'com.idle.tiny.%'),
first_seen AS (SELECT sku, MIN(d) first_day, MIN(IF(e='in_app_purchase', d, NULL)) first_buy_day FROM x GROUP BY sku)
SELECT x.sku, f.first_day, f.first_buy_day, x.d, x.v,
  COUNTIF(e='purchase_click') taps, COUNT(DISTINCT IF(e='purchase_click', u, NULL)) tappers,
  COUNTIF(e='in_app_purchase') buys, COUNT(DISTINCT IF(e='in_app_purchase', u, NULL)) buyers,
  SUM(IF(e='in_app_purchase', usd, 0)) usd
FROM x JOIN first_seen f USING (sku)
WHERE x.d >= '2026-09-04'
GROUP BY 1, 2, 3, 4, 5

-- Day-1 return by install day and install build, ex-China, installs 2026-09-18 .. 2026-10-15.
WITH ev AS (
  SELECT user_pseudo_id u, PARSE_DATE('%Y%m%d', event_date) d, event_name e, event_timestamp ts,
    app_info.version v, geo.country country
  FROM `tiny-knightfall-idle-rpg-game.analytics_538412813.events_intraday_*`
  WHERE _TABLE_SUFFIX BETWEEN '20260918' AND '20261016'
),
inst AS (
  SELECT u, MIN(d) install_d, ARRAY_AGG(v ORDER BY ts LIMIT 1)[OFFSET(0)] v, ANY_VALUE(country) country
  FROM ev WHERE e = 'first_open' GROUP BY u
)
SELECT i.install_d, i.v, COUNT(*) installs,
  COUNT(DISTINCT IF(a.d = DATE_ADD(i.install_d, INTERVAL 1 DAY), i.u, NULL)) d1_users
FROM inst i LEFT JOIN (SELECT DISTINCT u, d FROM ev WHERE e = 'user_engagement') a USING (u)
WHERE i.country != 'China' AND i.install_d <= '2026-10-15'
GROUP BY 1, 2

-- Event names first seen on or after 2026-10-02 (whole export), with the build they first appear in.
WITH e AS (
  SELECT event_name, app_info.version AS v, PARSE_DATE('%Y%m%d', event_date) AS d, user_pseudo_id AS u
  FROM `tiny-knightfall-idle-rpg-game.analytics_538412813.events_intraday_*`
),
first_seen AS (
  SELECT event_name, MIN(d) AS first_day, ARRAY_AGG(v ORDER BY d LIMIT 1)[OFFSET(0)] AS first_version
  FROM e GROUP BY event_name
)
SELECT f.event_name, f.first_day, f.first_version,
  STRING_AGG(DISTINCT e.v ORDER BY e.v) AS versions_seen, COUNT(*) AS events, COUNT(DISTINCT e.u) AS users
FROM first_seen f JOIN e USING (event_name)
WHERE f.first_day >= '2026-10-02'
GROUP BY 1, 2, 3
ORDER BY f.first_day, events DESC
