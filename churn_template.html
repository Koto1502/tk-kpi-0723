Inactive players by playtime

Players whose last heartbeat or user_engagement is at least 3 days old. Playtime uses online_time, falling back to summed engagement time, in 10-second bins.

Tutorial step exits

Shown only when a tutorial-step event or parameter exists.

Players left in game at each campaign level

A survival view: players who reached each level_start, regardless of whether they later became inactive.

Main quest reward funnel

Sequential earn events where position = main_quest, ordered by event time for each player. Quest N means the player recorded at least N main-quest reward claims.

Last custom event before player became inactive

The final game-defined event observed for 3-day-inactive players; automatic Firebase events are excluded.
